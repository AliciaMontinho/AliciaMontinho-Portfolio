# Alicia Montinho | Developer Portfolio

Welcome to my personal developer portfolio! 👋

This project is a personal website designed to showcase my skills, experience, projects and journey as a developer.

I'm a Web Application Development graduate (DAW) currently studying Multiplatform Application Development (DAM), passionate about technology, web design and creating useful, visually appealing digital experiences.

## 🚀 About the Project

This portfolio is built as a single-page application, with smooth navigation between sections and a responsive design.

It aims to bring together my technical knowledge, creativity and professional experience to demonstrate my approach to web development.

### Main Sections

- **Home:** Introduction and personal presentation.
- **About Me:** A little more about who I am and my interests.
- **Skills:** Technologies and tools I work with.
- **Experience:** My academic background and professional experience.
- **Projects:** A showcase of my development projects.
- **Contact:** A way to get in touch with me.

## 🛠️ Technologies

The project is being developed using:

- React
- TypeScript
- Vite
- HTML5
- CSS3
- Git
